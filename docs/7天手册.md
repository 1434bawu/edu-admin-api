## 1.1 先搞懂三个概念（30 分钟）

打开 <https://fastapi.tiangolo.com/zh/tutorial/first-steps/>，只看前两节。你要理解的就三件事：

| 概念 | 长什么样 | 作用 |
|---|---|---|
| `app` | `app = FastAPI()` | 整个服务的入口，uvicorn 加载的就是它 |
| 路由装饰器 | `@app.get("/students")` | 把下面的函数挂到「GET /students」这个地址上 |
| 返回值 | `return {"status": "ok"}` | 返回 dict，FastAPI 自动转成 JSON |

再加两个今天要用的：

- `@app.post(..., status_code=201)`：新增成功返回 201，不是 200
- `BaseModel`：声明请求体长什么样，FastAPI 自动帮你校验 + 写进 /docs

## 1.2 动手：把 `app/main.py` 改成这样

⚠️ **自己敲，不要复制粘贴**。敲完在每段上面加一行中文注释，说明这段在干嘛——加不出来就说明你没懂。

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI(title="教务管理系统 API", version="0.1.0")

# 内存里存学生，服务一重启就没了。Day 2 换成 SQLite。
students: list[dict] = []
next_id = 1


# 请求体的格式：学号、姓名必填，班级可以不填
class StudentIn(BaseModel):
    student_no: str
    name: str
    class_name: str = ""


@app.get("/health")
def health():
    return {"status": "ok"}


# 学生列表
@app.get("/students")
def list_students():
    return students


# 新增学生，成功返回 201
@app.post("/students", status_code=201)
def create_student(stu: StudentIn):
    global next_id
    # 学号不能重复，重复返回 409
    for s in students:
        if s["student_no"] == stu.student_no:
            raise HTTPException(status_code=409, detail="学号已存在")

    row = {"id": next_id, **stu.model_dump()}
    next_id += 1
    students.append(row)
    return row


# 查单个学生，找不到返回 404
@app.get("/students/{sid}")
def get_student(sid: int):
    for s in students:
        if s["id"] == sid:
            return s
    raise HTTPException(status_code=404, detail="学生不存在")
```

保存后 `--reload` 会自动重启。看终端，出现 `Application startup complete.` 就成了。

| 报错 | 原因 |
|---|---|
| `Could not import module "app.main"` | 文件名不是 `main.py`，或不在 `app/` 目录下 |

## 2.1 新建 `app/db.py`

```python
import sqlite3
from pathlib import Path

DB_PATH = Path(__file__).resolve().parent.parent / "edu.db"


def get_conn():
    conn = sqlite3.connect(DB_PATH)
    conn.row_factory = sqlite3.Row   # 让查询结果能按字段名取值
    return conn


def init_db():
    conn = get_conn()
    conn.executescript("""
    CREATE TABLE IF NOT EXISTS students (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        student_no TEXT UNIQUE NOT NULL,
        name TEXT NOT NULL,
        class_name TEXT,
        created_at TEXT DEFAULT CURRENT_TIMESTAMP
    );
    CREATE TABLE IF NOT EXISTS courses (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        name TEXT NOT NULL,
        credit REAL,
        teacher TEXT
    );
    CREATE TABLE IF NOT EXISTS scores (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        student_id INTEGER NOT NULL,
        course_id INTEGER NOT NULL,
        score REAL,
        term TEXT,
        FOREIGN KEY (student_id) REFERENCES students(id),
        FOREIGN KEY (course_id) REFERENCES courses(id)
    );
    """)
    conn.commit()
    conn.close()
```

然后在 `main.py` 顶部加：

```python
from app.db import get_conn, init_db

init_db()   # 启动时建表，表已存在就跳过
```

> `edu.db` 已经在 `.gitignore` 里了，不会提交到仓库，这是对的——数据库文件不该进 Git。

## 2.2 学生 CRUD 的写法（照着改）

新增：

```python
@app.post("/students", status_code=201)
def create_student(stu: StudentIn):
    conn = get_conn()
    try:
        cur = conn.execute(
            "INSERT INTO students (student_no, name, class_name) VALUES (?, ?, ?)",
            (stu.student_no, stu.name, stu.class_name),
        )
        conn.commit()
        sid = cur.lastrowid
    except sqlite3.IntegrityError:
        raise HTTPException(status_code=409, detail="学号已存在")
    finally:
        conn.close()
    return get_student(sid)
```

三个要点，自己想清楚再往下写：

1. **占位符 `?`**：不要用字符串拼接 SQL，那是注入漏洞
2. **`finally: conn.close()`**：不管成功失败都要关连接
3. **`sqlite3.IntegrityError`**：UNIQUE 冲突会抛这个，正好对应 409

剩下的 PUT / DELETE / 课程 / 成绩，全部是同一个套路：`get_conn()` → `execute` → `commit` → `close`。

## 2.3 今天要补的 6 个接口

| 接口 | 要点 |
|---|---|
| `PUT /students/{sid}` | 先查存不存在，不存在 404；更新后再查一次返回 |
| `DELETE /students/{sid}` | 不存在 404；成功返回 **204**（用 `status_code=204` 且 `return None`） |
| `POST /courses` | 学分不在 1–10 → 400 |
| `POST /scores` | 学生或课程不存在 → 404；分数不在 0–100 → 400 |
| `GET /students/{sid}/scores` | 两表 JOIN，学生不存在 → 404 |

## 5.1 `data/students.yaml`

```yaml
- case: 正常新增

  name: "张三"
  expect: 201
- case: 缺学号
  name: "李四"
  expect: 422
```

## 5.2 读 YAML + 参数化

```python
import yaml
from pathlib import Path

DATA = yaml.safe_load((Path(__file__).parent.parent / "data" / "students.yaml").read_text(encoding="utf-8"))


@pytest.mark.parametrize("case", DATA, ids=[c["case"] for c in DATA])
def test_create_student_cases(api, base_url, case):
    payload = {k: v for k, v in case.items() if k not in ("case", "expect")}
    r = api.post(f"{base_url}/students", json=payload)
    assert r.status_code == case["expect"]
```

`ids=` 很重要——报告里能直接看出是哪组数据挂了。

## 5.3 三层断言

```python
def assert_ok(resp, required: dict):
    """required 形如 {"id": int, "name": str}"""
    # 第一层：状态码
    assert resp.status_code in (200, 201), resp.text
    body = resp.json()
    # 第二层：结构（字段存在 + 类型对）
    for k, t in required.items():
        assert k in body, f"缺少字段 {k}"
        assert isinstance(body[k], t), f"{k} 类型应为 {t}"
    # 第三层：业务值（由调用方再断言）
    return body
```

然后每个用例里：`body = assert_ok(r, {"id": int, "name": str})` + `assert body["name"] == "张三"`。

**为什么要分三层**：状态码过但字段没了，只断言状态码的用例就是摆设。


双击 `reports/report.html` 就能看。`reports/` 已在 .gitignore 里，不会提交。

## 6.2 `.github/workflows/test.yml`

```yaml
name: api-test

on:
  push:
    branches: [main]
  pull_request:

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
          cache: pip

      - name: Install deps
        run: pip install -r requirements.txt pytest-html

      - name: Start server
        run: |
          uvicorn app.main:app --port 8000 &
          sleep 3

      - name: Run tests
        run: pytest -v --html=reports/report.html --self-contained-html

      - name: Upload report
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: pytest-report
          path: reports/
```

**要点**：`if: always()` 保证测试失败也把报告传上来，否则红了什么都看不到。
